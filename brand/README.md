# Projectify Zone — brand kit

The logo is drawn as PCB traces: single-weight strokes, 45° corners and round
solder pads. "PROJECT" and "Z" are cyan, "IFY" and "ONE" are pink, the same split
as the original neon sign. The flat version is the master logo because it
prints, works in Word, and stays sharp at any size. The glow is for dark
marketing material only.

## Which file to use

| Where | File |
| --- | --- |
| Word / Google Docs header, invoices, proposals (white page) | `png/docx-header.png` |
| Anything on a white or light background | `logo-horizontal-on-light` |
| Anything on a black or dark background | `logo-horizontal-on-dark` |
| Square-ish spaces: posters, social posts, banners | `logo-stacked-on-light` / `-on-dark` |
| Instagram / YouTube / event posters on dark | `png/logo-stacked-neon.png` |
| Profile pictures, app icon, WhatsApp DP | `png/icon-dark.png` (or `icon-light.png`) |
| One-colour printing: stamps, engraving, T-shirts, photocopies | `-black` / `-white` versions |
| Very tight spaces where the icon would be too small | `wordmark-*` (logo without the PZ tile) |

`svg/` holds the vector originals; use them for websites, print shops and
anything that needs to scale. `png/` holds transparent high-resolution exports
(2400px wide for horizontal, 2000px stacked, 1024px icons).

## Adding the logo to a Word header

1. Double-click the top margin of the page to open the header.
2. **Insert → Pictures → This Device** and pick `png/docx-header.png`.
3. Set the width to about **6–7 cm** (Picture Format → Size). Keep "Lock aspect ratio" on.
4. Optional: **Layout Options → In Line with Text** and align left, then add your
   contact details on the right.

## Colours

| | On dark backgrounds | On light backgrounds |
| --- | --- | --- |
| Cyan | `#22D3EE` | `#0891B2` |
| Pink | `#F472B6` | `#DB2777` |
| Ink / background | `#07090F` | `#FFFFFF` |

The light-background shades are deeper so they stay readable on white paper.

## Fonts

One family, **Archivo** (Google Fonts, free), in three widths:

- Headings: Archivo **Expanded**, semibold (in Word or Google Docs, choose "Archivo Expanded")
- Body text: Archivo, regular
- Tables, specs and small labels: Archivo **Condensed**

Dark backgrounds use soldermask blue `#0A1628` on the website; the logo files keep their own dark tile.

## Rules

- Don't stretch, rotate or recolour the logo; use the provided variants.
- Leave clear space around it at least the height of the letter "P".
- Don't use the neon version on light backgrounds or in documents.
- Smallest sizes: horizontal logo 120px / 3 cm wide; icon 16px.

## Editing

All files are generated by `generate.py` (letter shapes, spacing, colours).
Run `python3 brand/generate.py brand/svg` after editing it, then re-export the PNGs.
